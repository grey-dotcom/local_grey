# 업무 촬영 UX 정책 문서
버전 1.0 | 작성일 2026-03-09 | 대상 독자: 기획, 디자인, iOS/Android/Web FE, BE

---

## 1. 공통 운영 정책

### 촬영 원칙

실시간성 유지: 기기 내 앨범 호출(Image Picker) 불가. 오직 In-App 카메라로만 촬영 가능함.
위치 정보 증빙: 촬영 시 GPS 좌표를 메타데이터로 기록하여 현장 방문 사실을 백그라운드에서 증빙함.

### 워크플로우

자동 전환(Auto-Advance): 촬영 즉시 로컬 DB에 임시 저장하고, 다음 업무 도안으로 자동 이동함. 이동 대상은 아래 촬영 후 이동 정책을 따름.

### 사용자 환경

장갑 모드(Gloved Mode): 버튼 최소 터치 영역 44×44pt 유지. 셔터 버튼은 80pt 이상 권장함.
저조도 대응(Low-Light): 어두운 현장을 대비하여 뷰파인더 내 자동 노출 조정 기능을 적용함.

## 2. 핵심 인터랙션 정책

### 2-1. 촬영 후 자동 이동 정책 (Auto-Advance)

촬영 완료 즉시 아래 우선순위 순서대로 다음 화면을 결정함.

일반 촬영(첫 촬영)인 경우, 현재 도안 이후 순서에서 아직 촬영되지 않은 첫 번째 도안으로 이동함. 미촬영 도안이 더 이상 없으면 마지막 도안에 머무르며 업무 완료 버튼을 활성화함.

재촬영이고 모든 필수 도안이 이미 촬영 완료된 상태인 경우, 현재 도안 기준으로 순서상 바로 다음 도안(필수/선택 구분 없음)으로 이동함. 단, 현재 도안이 전체 마지막 도안이면 첫 번째 그룹의 첫 번째 도안으로 루프(Loop) 이동함.

재촬영이고 아직 촬영되지 않은 필수 도안이 남아있는 경우, 전체 그룹에서 순서상 가장 앞에 있는 미촬영 필수 도안으로 이동함.

| 시나리오 | 이동 대상 |
|---|---|
| 일반 촬영 | 다음 미촬영 도안. 없으면 마지막 도안 유지 |
| 재촬영 + 필수 전체 완료 + 마지막 도안 | 첫 번째 그룹 첫 번째 도안 (루프) |
| 재촬영 + 필수 전체 완료 + 그 외 | 순서상 바로 다음 도안 (선택 포함) |
| 재촬영 + 필수 미완료 | 첫 미촬영 필수 도안 |

### 2-2. 업무 완료 버튼 정책

업무 완료 버튼은 전체 도안 중 마지막 도안에 위치했을 때만 노출됨.

버튼이 노출된 상태에서 필수 도안이 하나라도 미촬영이면 버튼이 비활성(inactive) 상태로 표시됨. 이 상태에서 버튼을 탭하면 첫 번째 미촬영 필수 도안으로 이동함.

필수 도안이 모두 촬영 완료된 상태에서 버튼을 탭하면 촬영 화면을 종료(Navigator.pop)함.

### 2-3. 드롭다운 아코디언 정책

업무 도안 카드 내 안내문구(Contents) 영역은 기본 상태에서 1줄만 노출됨. 우측 Chevron(∨) 버튼 탭 시 아코디언 UI로 확장되어 전체 내용을 표시함. 확장 시 AnimatedSize(220ms, easeInOut) 애니메이션이 적용되며 Chevron 아이콘은 AnimatedRotation(220ms)으로 180도 회전함.

도안 간 이동 시 사용자가 마지막으로 설정한 드롭다운 상태(열림/닫힘)를 유지함. 도안이 바뀌어도 상태를 초기화하지 않음.

적용 범위는 모든 업무 그룹, 모든 업무 도안에 해당함.

## 3. 화면별 상세 기능

### 화면 1 — 업무 촬영 메인 (Camera Interface)

**상단 정보 영역 (Task Card)**

업무 그룹 타이틀: 현재 소속된 그룹명(예: 침실/거실)을 상단 중앙에 표시함. 좌측 뒤로가기 탭 시 촬영 화면에서 이탈하기 전 저장 안내 팝업을 노출함.

진행 상태 배지: [필수|선택] / [현재 순서] / [전체 수] 형태로 표시함. 필수 도안인 경우 배지 배경색을 #007AFF(Blue)로 강조하고, 선택 도안은 #F1F5F9(Gray)로 표시함.

업무 안내문구(Contents): 기본 1줄 노출. Chevron 탭 시 전체 내용 아코디언 확장. 줄 간격은 line-height 22.75px(font-size 14px 기준 1.625 배율) 적용.

페이지네이션: 그룹 내 도안 수만큼 인디케이터 표시함. 현재 도안은 원형 블루 배지(숫자 포함), 촬영 완료 도안은 블루 체크 원형, 미촬영 도안은 회색 점으로 구분함. 인디케이터 탭 시 해당 도안으로 즉시 이동함.

**카메라 뷰 영역 (Viewfinder)**

조작 안내 텍스트: 뷰파인더 상단 중앙에 고정 노출함. 첫 촬영 전에는 "스와이프하면 다음 업무 촬영이 가능해요" 문구를 표시함. 이미 촬영된 도안으로 진입 시 "저장된 사진이 있어요. 다시 촬영하려면 재촬영 버튼을 선택하세요." 문구로 자동 전환됨.

스와이프 제스처: 좌(←) 드래그 시 다음 도안, 우(→) 드래그 시 이전 도안으로 이동함. 촬영 완료 여부와 무관하게 미리보기 탐색 가능함. 임계값은 40px 이상 드래그 시 전환이 실행됨.

**하단 액션 영역 (Action Zone)**

셔터 버튼: 단일 탭으로 촬영 및 자동 저장/이동이 실행됨. 롱 탭에는 반응 없음. 촬영 완료된 도안 진입 시 셔터 텍스트가 '재촬영'으로 전환됨.

미리보기 썸네일: 재촬영 모드에서만 노출됨. 셔터 버튼 왼쪽 기준으로 배치되며, 셔터 왼쪽 엣지에서 50px 간격을 두고 썸네일 오른쪽 끝을 맞춤. 크기는 52×52px. 탭 시 전체 화면 모달로 기촬영 사진 확대 노출(줌 인/아웃 지원). 위치 계산 기준: 화면너비/2 − 셔터반지름(42px) − 간격(50px) − 썸네일크기(52px).

업무 완료 버튼: 전체 마지막 도안에서만 노출됨. 우측 하단 배치. 필수 미완료 시 비활성, 필수 전체 완료 시 활성으로 전환됨.

---

### 화면 2 — 재촬영 및 검토 (Re-capture)

진입 조건: 이미 사진이 임시 저장된 도안에 리스트 또는 스와이프를 통해 재진입했을 때.

재촬영 로직: 재촬영 셔터 탭 시 별도의 삭제 확인 없이 신규 사진이 기존 사진을 즉시 대체(Overwrite)함. 대체 후 촬영 후 이동 정책에 따라 자동 이동함.

---

### 화면 3 — 전체 업무 목록 (Task List Modal)

진입: 카메라 화면 우측 상단 리스트 아이콘 탭 시 바텀 시트 모달로 노출됨.

목록 구성: 관리자가 설정한 업무 순서(Index) 기준으로 정렬됨. 상태는 완료(블루 체크 + 회색 텍스트), 진행중(블루 텍스트 + 배경 하이라이트), 대기(일반 텍스트)로 구분됨.

이동: 각 항목 우측 Arrow 아이콘 탭 시 해당 도안 촬영 화면으로 즉시 이동하며 모달이 닫힘.

종료: 우측 상단 X 버튼 탭 시 모달 닫힘. 촬영 화면 유지.

## 4. 예외 처리 정책 (Exception Handling)

필수 촬영 누락: 업무 완료 시도 시 필수 항목이 미촬영 상태이면 버튼이 비활성 처리되며, 탭 시 첫 번째 미촬영 필수 도안으로 자동 이동함.

카메라 권한 거부: 앱 진입 시 카메라 권한을 확인함. 거부 상태이면 시스템 설정으로 유도하는 안내 화면을 노출하고, 재시도 버튼 탭 시 권한 요청을 재실행함.

업로드 실패: 촬영 데이터는 로컬에 우선 저장(임시 저장)한 뒤 백그라운드에서 서버 전송을 시도함. 전송 실패 시 썸네일 우측 하단에 오류 배지를 노출함. 앱 재실행 시 미전송 데이터를 감지하여 자동 재전송을 시작함.

저장 공간 부족: 촬영 전 기기 용량을 확인함. 부족 시 촬영 기능을 비활성화하고 알림 팝업을 노출함.

## 5. 미구현 항목 (개발 예정)

아래 항목은 정책은 확정되었으나 현재 Web Prototype(Flutter Web)에는 미반영 상태이며, iOS/Android 네이티브 앱 개발 시 구현 예정임.

GPS 메타데이터 기록: `native_camera_service.dart` 스텁으로 인터페이스만 정의됨.
그룹 전환 화면 (Transition Screen): 필수 도안 전체 완료 시 자동 진입 화면. 현재 미구현.
그룹 이동 오버레이: 이전 그룹으로 즉시 이동하는 하단 오버레이. 현재 미구현.
업로드 실패 시 재전송 큐: 현재 단순 오류 배지 표시만 구현됨.
필수 누락 강제 팝업: 현재 자동 이동으로 처리 중. 리스트 모달 강제 팝업은 미구현.
