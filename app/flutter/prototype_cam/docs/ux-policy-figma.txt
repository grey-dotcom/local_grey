업무 촬영 UX 정책
버전 2.0  |  2026-03-17  |  기획 · 디자인 · iOS/Android FE · BE 공통

v1.0 대비 변경: 촬영 완료 처리 방식 변경, 전체 업무 목록 상태값 5종으로 확장, 사진 업로드 & 수행완료 정책 신규 추가, 시작화면 버튼 구조 변경


1. 촬영 원칙
사용자는 앱 안에 내장된 카메라로만 사진을 찍을 수 있습니다.
기기의 갤러리나 앨범에서 사진을 가져오는 것은 불가합니다.
촬영 시 GPS 좌표가 자동으로 기록되어 현장 방문 사실이 백그라운드에서 증빙됩니다.

2. 화면 구조
촬영 화면은 위에서 아래 순서로 4개 영역으로 나뉩니다.

(1) 헤더 — 그룹명과 이전 그룹 이동 도트가 표시되는 최상단 영역입니다.
(2) 배지 영역 — 현재 도안이 필수인지 선택인지를 알려주는 배지와 전체 도안 중 몇 번째인지를 숫자로 보여줍니다. 배지 높이는 26px로 고정됩니다. 우측에는 전체 업무 목록을 열 수 있는 리스트 버튼이 있습니다.
(3) 도안 안내 영역 — 현재 촬영해야 할 업무의 이름(타이틀)과 상세 안내 문구(컨텐츠)가 표시됩니다. 안내 문구는 기본적으로 한 줄만 보이며, 우측 화살표를 탭하면 전체 내용이 펼쳐집니다. 펼침 상태는 도안을 이동해도 유지됩니다.
(4) 캐러셀 영역 — 현재 그룹 안에 있는 전체 도안의 수만큼 점이 표시됩니다. 현재 도안은 파란 원(링 포함 24px), 이미 찍은 도안은 체크 표시 원(20px), 아직 안 찍은 도안은 회색 작은 점(8px)으로 구분됩니다. 점을 직접 탭하면 해당 도안으로 바로 이동합니다. 캐러셀 아래에는 구분선이 없습니다.

3. 도안 이동 방법
사용자는 세 가지 방법으로 도안 사이를 이동할 수 있습니다.
카메라 화면 영역을 좌우로 밀면(스와이프) 이동합니다. 40px 이상 밀었을 때 전환이 실행됩니다.
왼쪽으로 밀면 다음 도안, 오른쪽으로 밀면 이전 도안으로 이동합니다.
화면 좌우에 표시된 화살표 버튼을 탭해서 이동할 수 있습니다.
캐러셀의 특정 점을 탭하면 해당 도안으로 바로 이동합니다.
이동 방향은 순환(Loop) 구조입니다.
마지막 도안에서 다음으로 이동하면 첫 번째 도안으로 돌아오고, 첫 번째 도안에서 이전으로 이동하면 마지막 도안으로 이동합니다.

4. 촬영 후 자동 이동 정책
사진을 찍으면 앱이 자동으로 다음 화면으로 이동합니다.
아래 순서대로 이동 대상이 결정됩니다.
처음 찍는 경우 — 현재 도안 이후에 아직 찍지 않은 첫 번째 도안으로 이동합니다. 더 이상 안 찍은 도안이 없으면 마지막 도안에 그대로 머무릅니다.
재촬영이고 필수 도안을 모두 찍은 경우 — 촬영 화면이 자동으로 종료되고 시작화면으로 돌아갑니다.
재촬영이고 아직 안 찍은 필수 도안이 남아있는 경우 — 전체 도안 중 순서상 가장 앞에 있는 미촬영 필수 도안으로 이동합니다.

5. 촬영 완료 처리 [v2.0 변경]
모든 필수 도안 촬영이 완료되면 별도의 버튼 없이 앱이 자동으로 촬영 화면을 종료하고 시작화면으로 돌아갑니다.
사용자가 완료 버튼을 따로 누를 필요가 없습니다.
촬영 화면 종료 직후 "모든 촬영이 완료되었습니다" 토스트 메시지가 1.5초간 표시됩니다(fadeIn 200ms → 유지 1100ms → fadeOut 200ms).

6. 재촬영 화면
이미 사진이 저장된 도안으로 스와이프나 리스트를 통해 다시 진입하면 재촬영 화면이 열립니다.
카메라 화면 상단의 안내 문구가 "저장된 사진이 있어요. 다시 촬영하려면 재촬영 버튼을 선택하세요."로 바뀝니다.
셔터 버튼 안에 "재촬영" 텍스트가 표시됩니다.
탭하면 기존 사진을 지우는 확인 절차 없이 바로 새 사진으로 교체됩니다.
셔터 버튼 왼쪽에 기존에 찍은 사진의 작은 썸네일(52×52px)이 표시됩니다.
썸네일을 탭하면 전체 화면으로 사진을 크게 볼 수 있으며 핀치 줌으로 확대/축소도 가능합니다.
썸네일 우측 하단에는 현재 업로드 상태 아이콘이 표시됩니다. 업로드 중이면 스피너, 완료이면 체크, 실패이면 느낌표 아이콘이 나타납니다.
캐러셀에서 이미 찍은 도안의 점은 체크 표시 원으로 바뀝니다. 현재 재촬영 중인 도안은 링이 있는 파란 원으로 표시됩니다.

7. 전체 업무 목록 (리스트 모달) [v2.0 변경]
배지 영역 우측의 리스트 버튼을 탭하면 아래에서 올라오는 모달로 전체 업무 목록이 열립니다.
목록은 관리자가 설정한 순서대로 표시됩니다.
각 항목은 아래 5가지 상태에 따라 다르게 표시됩니다.

완료 — 사진이 서버까지 업로드 완료된 상태입니다. 파란 체크 아이콘과 회색 텍스트로 표시됩니다.
진행중 — 현재 포커스된 도안이 첫 촬영인 경우입니다. 파란 테두리와 파란 텍스트로 강조됩니다.
대기 — 아직 촬영하지 않은 도안입니다. 회색 번호와 일반 텍스트로 표시됩니다.
업로드중 — 촬영은 완료됐으나 서버로 전송 중인 도안입니다. 스피너 아이콘과 연파랑 뱃지로 표시됩니다. 재촬영한 경우도 동일하게 적용됩니다.
에러(재시도) — 업로드가 실패한 도안입니다. 빨간 테두리와 "재시도" 뱃지가 표시되며 재시도 버튼을 탭하면 다시 전송을 시도합니다.

항목 우측의 화살표를 탭하면 해당 도안 촬영 화면으로 바로 이동하면서 모달이 닫힙니다.
업로드중인 도안도 탭하여 재촬영 화면으로 진입할 수 있습니다.
우측 상단의 X 버튼을 탭하면 모달만 닫히고 촬영 화면은 그대로 유지됩니다.

8. 사진 업로드 & 수행완료 정책 [신규 v2.0]
사진 누락으로 인한 클레임을 방지하고 불안정한 네트워크 환경에서도 안정적인 업무 처리를 보장하기 위한 정책입니다.

필수 사진은 모두 서버 업로드가 완료되어야 수행완료가 가능합니다. 선택 사진은 촬영하지 않아도 수행완료에 영향이 없습니다.

사용자가 촬영한 사진은 업로드 완료 전까지 기기에 보존됩니다. 서버 업로드에 성공하면 서버 기준으로 관리하며 기기에서 삭제됩니다. 오프라인 상태에서 촬영한 사진은 기기에 저장해 두었다가 네트워크가 연결되면 자동으로 업로드됩니다.

같은 도안을 여러 장 연속 촬영할 경우 마지막에 찍은 사진만 서버로 전송됩니다. 업로드 실패 사진은 기기에 유지되며 사용자가 언제든 재시도할 수 있습니다. 네트워크 오류 등 일시적인 실패는 재시도 버튼을 통해 다시 시도할 수 있고, 파일 형식 오류 등 근본적인 실패는 재촬영을 유도합니다.

어드민이 미리 업로드한 사진이 있는 도안은 사진촬영 화면 진입 시 재촬영 상태로 표시됩니다. 단, 이 정보는 화면을 새로 불러올 때(리프레시)만 반영됩니다.

9. 시작화면 수행완료 버튼 [신규 v2.0]
시작화면 하단 버튼은 촬영 및 업로드 상태에 따라 세 단계로 전환됩니다.

필수 도안 미촬영 상태에서는 등록 완료 버튼이 비활성(회색)으로 표시됩니다. 탭하면 미촬영 항목 안내 팝업이 노출됩니다.

필수 도안 촬영 완료 상태에서는 수행완료 버튼이 활성(파랑)으로 표시됩니다. 이 시점에 사용자는 시작화면에서 각 사진 셀을 선택해 재촬영할 수 있습니다. 수행완료를 탭했을 때 모든 사진 업로드가 완료된 상태라면 즉시 등록완료 처리됩니다. 아직 업로드가 진행 중이라면 등록 완료 - 업로드중 버튼이 비활성 상태로 전환되며 업로드가 끝나면 자동으로 등록완료 처리됩니다.

10. 접근성
모든 버튼의 최소 터치 영역은 44×44pt 이상입니다.
셔터 버튼은 80pt 이상을 권장합니다.
장갑을 낀 상태에서도 조작할 수 있도록 설계되었습니다.
어두운 환경에서도 촬영이 가능하도록 카메라 뷰파인더에 자동 노출 조정이 적용됩니다.

11. 현재 미구현 항목 (추후 네이티브 앱에서 적용 예정)
GPS 메타데이터 기록, 그룹 전환 화면, 이전 그룹으로 이동하는 하단 오버레이, 오프라인 자동 재업로드(ConnectivityResult 감지), 수행완료 API 자동 연동, 어드민 업로드 사진 상태 초기화 조회, 수행전/후 사진 촬영 화면(다음 스펙 이관)은 현재 웹 프로토타입에는 구현되지 않았으며 네이티브 앱 개발 시 적용됩니다.
