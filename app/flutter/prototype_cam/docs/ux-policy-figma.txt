업무 촬영 UX 정책
버전 1.0  |  2026-03-09  |  기획 · 디자인 · iOS/Android FE · BE 공통


────────────────────────────────────────
1. 공통 운영 정책
────────────────────────────────────────

촬영 원칙

    실시간성 유지
    기기 내 앨범 호출(Image Picker) 불가. 오직 In-App 카메라로만 촬영 가능함.

    위치 정보 증빙
    촬영 시 GPS 좌표를 메타데이터로 기록하여 현장 방문 사실을 백그라운드에서 증빙함.

워크플로우

    자동 전환 (Auto-Advance)
    촬영 즉시 로컬 DB에 임시 저장하고, 다음 업무 도안으로 자동 이동함.
    이동 대상은 아래 2-1 촬영 후 이동 정책을 따름.

사용자 환경

    장갑 모드 (Gloved Mode)
    버튼 최소 터치 영역 44×44pt 유지. 셔터 버튼은 80pt 이상 권장함.

    저조도 대응 (Low-Light)
    어두운 현장을 대비하여 뷰파인더 내 자동 노출 조정 기능을 적용함.


────────────────────────────────────────
2. 핵심 인터랙션 정책
────────────────────────────────────────

2-1. 촬영 후 자동 이동 정책 (Auto-Advance)

    촬영 완료 즉시 아래 순서대로 다음 화면을 결정함.

    [일반 촬영 — 해당 도안 첫 촬영인 경우]
    현재 도안 이후 순서에서 아직 촬영되지 않은 첫 번째 도안으로 이동함.
    미촬영 도안이 없으면 마지막 도안에 머무르며 업무 완료 버튼을 활성화함.

    [재촬영 + 필수 도안 전체 완료 상태]
    현재 도안 기준 순서상 바로 다음 도안(필수/선택 구분 없음)으로 이동함.
    현재 도안이 전체 마지막 도안이면 첫 번째 그룹의 첫 번째 도안으로 루프(Loop) 이동함.

    [재촬영 + 필수 도안 미완료 상태]
    전체 그룹에서 순서상 가장 앞에 있는 미촬영 필수 도안으로 이동함.

    시나리오 요약

        일반 촬영
        → 다음 미촬영 도안. 없으면 마지막 도안 유지.

        재촬영 + 필수 전체 완료 + 마지막 도안
        → 첫 번째 그룹 첫 번째 도안 (루프)

        재촬영 + 필수 전체 완료 + 그 외
        → 순서상 바로 다음 도안 (선택 포함)

        재촬영 + 필수 미완료
        → 첫 미촬영 필수 도안


2-2. 업무 완료 버튼 정책

    노출 조건
    전체 도안 중 마지막 도안에 위치했을 때만 노출됨.

    비활성 상태 (Inactive)
    필수 도안이 하나라도 미촬영이면 버튼을 비활성으로 표시함.
    이 상태에서 탭하면 첫 번째 미촬영 필수 도안으로 이동함.

    활성 상태 (Active)
    필수 도안이 모두 촬영 완료된 상태에서 탭하면 촬영 화면을 종료함.


2-3. 드롭다운 아코디언 정책

    기본 상태
    업무 도안 카드 내 안내문구(Contents) 영역은 1줄만 노출됨.

    확장 상태
    우측 Chevron(∨) 탭 시 아코디언 UI로 전체 내용 표시.
    애니메이션: AnimatedSize 220ms easeInOut.
    Chevron 아이콘: AnimatedRotation 220ms, 180도 회전.

    도안 이동 시 상태 유지
    도안 간 이동 시 사용자가 마지막으로 설정한 드롭다운 상태(열림/닫힘)를 유지함.
    도안이 바뀌어도 상태를 초기화하지 않음.

    적용 범위
    모든 업무 그룹, 모든 업무 도안에 해당함.


────────────────────────────────────────
3. 화면별 상세 기능
────────────────────────────────────────

화면 1 — 업무 촬영 메인 (Camera Interface)

    상단 정보 영역 (Task Card)

        업무 그룹 타이틀
        현재 소속된 그룹명(예: 침실/거실)을 상단 중앙에 표시함.
        좌측 뒤로가기 탭 시 촬영 화면 이탈 전 저장 안내 팝업을 노출함.

        진행 상태 배지
        [필수|선택] / [현재 순서] / [전체 수] 형태로 표시함.
        필수 도안: 배지 배경색 #007AFF(Blue).
        선택 도안: 배지 배경색 #F1F5F9(Gray).

        업무 안내문구 (Contents)
        기본 1줄 노출. Chevron 탭 시 전체 내용 아코디언 확장.
        줄 간격: line-height 22.75px (font-size 14px 기준 1.625 배율).

        페이지네이션
        그룹 내 도안 수만큼 인디케이터 표시.
        현재 도안: 원형 블루 배지 (숫자 포함).
        촬영 완료: 블루 체크 원형.
        미촬영: 회색 점.
        인디케이터 탭 시 해당 도안으로 즉시 이동함.

    카메라 뷰 영역 (Viewfinder)

        조작 안내 텍스트
        뷰파인더 상단 중앙에 고정 노출함.
        미촬영 도안: "스와이프하면 다음 업무 촬영이 가능해요"
        촬영 완료 도안: "저장된 사진이 있어요. 다시 촬영하려면 재촬영 버튼을 선택하세요."

        스와이프 제스처
        좌(←) 드래그: 다음 도안 이동.
        우(→) 드래그: 이전 도안 이동.
        촬영 완료 여부와 무관하게 탐색 가능. 임계값 40px 이상.

    하단 액션 영역 (Action Zone)

        셔터 버튼
        단일 탭: 촬영 및 자동 저장/이동 실행.
        롱 탭: 반응 없음.
        촬영 완료 도안 진입 시 버튼 텍스트 '재촬영'으로 전환됨.

        미리보기 썸네일
        재촬영 모드에서만 노출됨.
        위치: 셔터 왼쪽 엣지에서 50px 간격을 두고 썸네일 오른쪽 끝을 맞춤.
        크기: 52×52px.
        위치 계산: 화면너비 ÷ 2 − 셔터반지름(42px) − 간격(50px) − 썸네일크기(52px).
        탭 시 전체 화면 모달로 기촬영 사진 확대 노출. 줌 인/아웃 지원.

        업무 완료 버튼
        전체 마지막 도안에서만 노출됨. 우측 하단 배치.
        필수 미완료: 비활성. 필수 전체 완료: 활성.


화면 2 — 재촬영 및 검토 (Re-capture)

    진입 조건
    임시 저장된 도안에 리스트 또는 스와이프를 통해 재진입했을 때.

    재촬영 로직
    재촬영 셔터 탭 시 별도의 삭제 확인 없이 신규 사진이 기존 사진을 즉시 대체(Overwrite)함.
    대체 후 2-1 촬영 후 이동 정책에 따라 자동 이동함.


화면 3 — 전체 업무 목록 (Task List Modal)

    진입
    카메라 화면 우측 상단 리스트 아이콘 탭 시 바텀 시트 모달로 노출됨.

    목록 구성
    정렬: 관리자가 설정한 업무 순서(Index) 기준.
    완료: 블루 체크 아이콘 + 회색 텍스트.
    진행중: 블루 텍스트 + 배경 하이라이트.
    대기: 일반 텍스트.

    이동
    각 항목 우측 Arrow 아이콘 탭 시 해당 도안으로 즉시 이동하며 모달 닫힘.

    종료
    우측 상단 X 탭 시 모달 닫힘. 촬영 화면 유지.


────────────────────────────────────────
4. 예외 처리 정책 (Exception Handling)
────────────────────────────────────────

    필수 촬영 누락
    업무 완료 버튼이 비활성 처리됨. 탭 시 첫 번째 미촬영 필수 도안으로 자동 이동함.

    카메라 권한 거부
    앱 진입 시 권한 확인. 거부 상태이면 시스템 설정 유도 안내 화면 노출.
    재시도 버튼 탭 시 권한 요청 재실행.

    업로드 실패
    촬영 데이터는 로컬에 우선 저장 후 백그라운드에서 서버 전송 시도.
    실패 시 썸네일 우측 하단에 오류 배지 노출.
    앱 재실행 시 미전송 데이터 감지 후 자동 재전송 시작.

    저장 공간 부족
    촬영 전 기기 용량 확인. 부족 시 촬영 기능 비활성화 및 알림 팝업 노출.

5. 미구현 항목 — 네이티브 앱 개발 예정
────────────────────────────────────────

    아래 항목은 정책 확정 완료. 현재 Flutter Web Prototype에는 미반영.
    iOS / Android 네이티브 앱 개발 단계에서 구현 예정.

    GPS 메타데이터 기록
    native_camera_service 스텁으로 인터페이스만 정의된 상태.

    그룹 전환 화면 (Transition Screen)
    필수 도안 전체 완료 시 자동 진입 화면. 현재 미구현.

    그룹 이동 오버레이
    이전 그룹으로 즉시 이동하는 하단 오버레이. 현재 미구현.

    업로드 실패 재전송 큐
    현재 단순 오류 배지 표시만 구현됨.

    필수 누락 강제 팝업
    현재 자동 이동으로 처리 중. 리스트 모달 강제 팝업은 미구현.
