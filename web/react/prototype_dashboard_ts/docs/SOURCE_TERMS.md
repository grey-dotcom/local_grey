# 실 서비스 화면 용어 원문
> 목적: 실 서비스에서 직접 확인한 용어·컬럼·버튼·필터 원문 기록
> 가드레일: 추론·해석·정책 판단 기록 금지. 확인된 사실만 기록.
> 수정 방식: 기존 내용 수정 금지. 새 탐색 시 날짜와 함께 섹션 추가.
> 하네스 위치: 기획서(SPEC) 작성 파이프라인 — 참고 검증 요소
> 기획서 작성 시 FE 역할 체크리스트 3번 항목으로 활용

출처: indicator-dev.vercel.app 직접 화면 확인 (2026-04-03)

## 홈(대시보드) 화면 용어

페이지 제목 없음 (사이드바 메뉴: 홈 > 대시보드)

상단 공통 영역
- 새로고침 (버튼)
- 지점 선택 (드롭다운 라벨)

섹션 1 타이틀: 오늘의 할 일
- 날짜 표시 형식: N월N일 요일 (예: 04월03일 금요일)
- 업데이트 시각 표시: 업데이트: MM-DD HH:mm

오늘의 완성률 영역
- 오늘의 완성률 (카드 타이틀)
- 총 (레이블)
- 수행 완료 (레이블)
- 미수행 (레이블)
- 표시 형식: N% / (완료건/전체건)

완성률 툴팁 전문
- 제목: 오늘의 완성률이란?
- 내용 1: 오늘(00:00~23:59) 예정된 전체 일감 진행 현황을 수행 완료/미수행 상태로 구분하여 차트로 보여줍니다.
- 내용 2: 집계 대상: 시작 가능 일시가 오늘인 일감이 포함됩니다. 단, '보고됨' 상태의 이슈는 시작 가능 일시와 상관없이 모든 이슈가 포함됩니다.
- 내용 3: 데이터 갱신: 1분마다 자동으로 갱신되며, 필요 시 수동으로 새로고침 할 수 있습니다.

일감 상태별 건수 카드 8종 (화면 표시 라벨)
- 보고됨
- 미배정
- 배정됨
- 수행전
- 수행중
- 완료
- 보류
- 취소 (분홍 배경으로 구분)

섹션 2 타이틀: 처리 필요

처리 필요 정렬 옵션 3종
- 최신 등록순
- 오래된 순
- 공간 이용 임박순

처리 필요 생성 주체 필터 3종
- 전체
- 키퍼
- 관제자

처리 필요 테이블 컬럼
- 항목, 지점, 건물번호, 공간 이름, 생성 주체, 생성 일시

처리 필요 빈 상태 문구: 처리 대기 중인 항목이 없습니다.

## 관제 화면 — 일감/이슈 현황

페이지 타이틀: 일감/이슈 현황 (N) [실시간 갱신 초록 점 포함]

상단 필터 영역
- 조회 일자 (날짜 선택, 달력 아이콘)
- 지점 선택 (드롭다운, X 버튼으로 초기화)
- 일감 상태 (드롭다운)
- 우선 수행 요청 (드롭다운)
- 검색 (텍스트 입력, 돋보기 아이콘)

일감 상태 드롭다운 옵션 7종
- 전체, 보고됨, 미배정, 배정됨, 수행전, 수행중, 보류
- 완료·취소는 이 필터 목록에 없음

우선 수행 요청 드롭다운 옵션 3종
- 전체
- 우선 수행 요청
- - (없음)

상단 버튼 5종
- 컬럼 설정
- 반복 일감 관리
- 이슈 생성
- 일감 생성
- 일감 배정

테이블 컬럼 전체 목록
- 번호, 일감, 일감 상태, 우선 수행 요청, 지점, 공간 타입, 동, 층, 공간 이름
- 생성 주체, 보고사항, 일감 참고사항
- 공간 이용 종료 일시, 배정 가능 일시, 시작 가능 일시, 시작 기한, 완료 기한
- 시작 예정 일시, 배정된 시각, 시작된 시각, 완료된 시각, 취소된 시각
- 다음 공간 이용 일시, 키퍼, 키퍼 레벨, 일감 경험치, 생성된 시각, 티켓 ID

## 일감 상세 모달

모달 타이틀: 일감 정보

상태 스텝 표시 (8단계)
1.보고됨 → 2.미배정 → 3.배정됨 → 4.수행전 → 5.수행중 → 6.완료 → 7.보류 → 8.취소

탭 3종: 기본 정보 / 키퍼/일정 정보 / 수행 정보

기본 정보 탭 — 일감 정보 섹션
- 티켓 ID
- 생성 주체
- 우선 수행 요청 (배지, 빨간 테두리)

기본 정보 탭 — 공간 정보 섹션
- 지점 주소, 지점, 동, 공간 이름, 층, 활성 여부, 공간 타입

기본 정보 탭 — 공간 이용 종료~시작 일시 섹션
- 날짜별 공간 이용 종료 시각 ~ 시작 시각 표시

키퍼/일정 정보 탭 — 수행 일정 섹션
- 생성 일시, 예상 소요 시간
- 배정 가능 일시, 시작 예정 일시, 시작 가능 일시, 시작된 시각
- 시작 기한, 완료된 시각, 완료 기한

키퍼/일정 정보 탭 — 키퍼 및 가격 정보 섹션
- 공급가, 파트너가, 키퍼, 키퍼 레벨, 키퍼가, 일감 경험치

수행 정보 탭
- 일감 참고사항 (등록 버튼 포함)
- 일감 결과표 (항목별 체크 + 사진 추가)

모달 우측 패널
- 연결된 티켓 현황 (카드형)
- 후속 일감 생성 (버튼)
- 변경 이력 (상태 변경 타임라인)

모달 하단 버튼
- 취소 상태로 변경 (좌측, 빨간 테두리)
- 강제로 상태 변경 (토글)
- 미배정 / 수행전 / 완료 (우측 버튼 3종)
