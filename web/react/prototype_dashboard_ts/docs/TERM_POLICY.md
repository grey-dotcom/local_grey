## §1. 역할 주체 용어

| 용어 | 정의 | 사용 범위 |
|---|---|---|
| 운영자 | 대시보드를 사용하는 관제사·파트너사 담당자 | 기획서 전체 |
| 키퍼 | 현장에서 일감을 수행하는 실행 인력 | 기획서·정책서 |
| 관제사 | 일감을 생성·배정·관리하는 운영 담당자 | 기획서·정책서 |
| 고객사 | 클레임을 등록하는 주체 (투숙객 등) | 클레임 기획서 |
| 파트너사 | 클레임에 인정 또는 이의제기로 응답하는 주체 | 클레임 기획서 |

## §2. 화면 구조 용어

| 용어 | 정의 | 비고 |
|---|---|---|
| 대시보드 | 실 서비스 홈 화면. 오늘의 할 일 + 처리 필요 섹션으로 구성. | 실 서비스: /home |
| 지점 | 운영 대상 공간의 최상위 단위 (호텔·건물 등) | |
| 공간 | 지점 내 개별 실(객실·구역 등) | |
| 공간 타입 | 공간의 유형 분류 (예: A타입) | |
| 워크스페이스 | 운영자가 소속된 조직 단위 | 실 서비스 좌측 상단 드롭다운 |

## §3. 일감(티켓) 관련 용어

| 용어 | 정의 | 실 서비스 표현 |
|---|---|---|
| 일감 | 키퍼에게 배정되는 작업 단위 | 일감 |
| 티켓 | 일감과 동일 개념. BE·코드 내부 용어. | ticket (코드), 일감 (화면) |
| 반복 일감 | 매일 자동 생성되는 정기 일감 | 반복 일감 |
| 우선 수행 요청 | 일감의 긴급 처리 요청 플래그 | 우선 수행 요청 (배지) |
| 시작 가능 일시 | 일감 수행을 시작할 수 있는 일시 | 시작 가능 일시 |
| 배정 가능 일시 | 키퍼 배정이 가능한 시작 일시 | 배정 가능 일시 |
| 시작 기한 | 수행을 시작해야 하는 마감 일시 | 시작 기한 |
| 완료 기한 | 수행을 완료해야 하는 마감 일시 | 완료 기한 |

## §4. 이슈 관련 용어

| 용어 | 정의 | 실 서비스 표현 |
|---|---|---|
| 이슈 | 키퍼가 현장에서 보고한 문제 (파손·오염·비품 부족 등) | 보고됨(REPORTED) 상태 |
| 보류 | 접수된 이슈 중 즉시 처리가 어려워 일시 중단된 상태 | 보류(HOLD) |
| 처리 필요 | 대시보드 홈의 미처리 이슈 목록 섹션 | 처리 필요 |

---

## §5. 클레임 관련 용어

| 용어 | 정의 | 실 서비스 표현 |
|---|---|---|
| 클레임 | 고객사가 서비스 품질에 이의를 제기하는 건 | 클레임 |
| 처리 대기 | 파트너사가 아직 처리하지 않은 클레임 상태 | 처리 대기(PENDING) |
| 인정완료 | 파트너사가 클레임을 인정하여 종결한 상태 | 인정완료(ACCEPTED) |
| 이의제기 | 파트너사가 클레임에 이의를 제기하여 종결한 상태 | 이의제기(DISPUTED) |
| 이의제기 후속 처리 완료 | 이의제기 후 후속 업무까지 완료된 상태 | 이의제기 후속 처리 완료(DISPUTE_COMPLETED) |

---

## §6. 집계·달성률 관련 용어

| 용어 | 정의 |
|---|---|
| 오늘의 완성률 | 오늘(00:00~23:59) 예정 일감 중 수행 완료 비율 |
| 업무 현황 | 시작 가능 일시 기준 오늘 이하이며 미완료인 일감 수 |
| 미해결 이슈 | 접수됨(REPORTED) + 보류(HOLD) 상태 이슈의 합계 |
| 미확인 클레임 | 처리 대기(PENDING) 상태 클레임 수 |
| 달성률 분모 | 오늘 00:00 기준 미완료 전체 스냅샷 + 당일 신규 생성 누적 |
| 달성률 분자 | 오늘 완료된 일감 + 이슈 + 클레임 합계 |
