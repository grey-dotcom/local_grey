## 1. 필터 탭 ↔ TicketStatus 매핑 (확정)

| 필터 탭 | FeedFilter 값 | 포함 TicketStatus | 추가 조건 |
|---|---|---|---|
| 전체 | `ALL` | 8개 전부 | — |
| 지연/임박 | `DELAY` | REPORTED, UNASSIGNED, ASSIGNED, BEFORE_START | `dueAt` 기준 **30분 이내** 미완료 |
| 취소 | `CANCELLED` | CANCELLED, ON_HOLD | — |
| 시작 | `STARTED` | IN_PROGRESS | — |
| 완료 | `COMPLETED` | COMPLETED | — |

**모바일 전용 탭 (추가 여부 미확정)**:
- "일감 관리" (`MANAGEMENT`): REPORTED ~ COMPLETED 전체 운영 상태 (시간 조건 없음)
- 데스크탑에는 없음. 추가 여부 PM 결정 대기.

**지연/임박 판정 로직** (FE 계산):
- 임계값: `30분` (변경 가능, 상수로 분리)
- `remaining = dueAt - now`
- `remaining < 0` → **지연** (초과)
- `0 < remaining <= 30분` → **임박**
- 대상 상태: REPORTED, UNASSIGNED, ASSIGNED, BEFORE_START만

## 2. 카드 유형 전체 정의

### 2-1. 지연/임박 카드 (4가지)

| # | 조건 | 배지 | 좌측바 | 카드 배경 | 시간 표시 | 버튼 |
|---|---|---|---|---|---|---|
| 1 | NEW + REPORTED/UNASSIGNED/ASSIGNED/BEFORE_START + 임박/지연 | NEW + "일감 마감 지연" 또는 "마감 시간 임박" + taskType | `#FF1744` | `#F5F5F5` (NEW) | 빨강 "+N분 초과" 또는 "마감 N분 전" | 긴급 변경 + 완료 |
| 2 | NEW + IN_PROGRESS + 임박/지연 | NEW + 상태배지 + taskType | `#FF1744` | `#F5F5F5` | 빨강 | 긴급 취소 + 완료 |
| 3 | 확인됨 + 임박/지연 | 상태배지 + taskType | `#FF1744` | white | 빨강 | 완료 |
| 4 | COMPLETED + 원래 지연/임박이었던 건 | ✓완료 + 원래 상태배지 + taskType | `#FF1744` | white | 빨강 | 되돌리기 |

**긴급 버튼 분기 규칙**:
- 기저 상태가 REPORTED / UNASSIGNED / ASSIGNED / BEFORE_START → **긴급 변경**
- 기저 상태가 IN_PROGRESS → **긴급 취소**

### 2-2. 일감 관리 카드 (5가지)

| # | TicketStatus | 배지 | 좌측바 | 메모 영역 | 버튼 |
|---|---|---|---|---|---|
| 1 | REPORTED / UNASSIGNED | "신규" (파란 테두리) | 회색/없음 | ✅ 작성 가능 | 긴급변경 + 일감취소 + 배정하기 |
| 2 | ASSIGNED | "배정 완료" (초록) | `#9E9E9E` | ✅ 작성 가능 | 긴급변경 + 배정해제 + 시작하기 |
| 3 | IN_PROGRESS | "수행중" (초록) | 초록 계열 | ✅ 작성 가능 | 긴급변경 + 시작취소 + 완료하기 |
| 4a | COMPLETED (내용 없음) | "✓ 완료" (초록+체크) | `#9E9E9E` | ✗ | 되돌리기 |
| 4b | COMPLETED (내용 있음) | "✓ 완료" (초록+체크) | `#9E9E9E` | 읽기전용 (파란 테두리) | 되돌리기 |

**BEFORE_START(수행전)**: ASSIGNED와 동일 카드 디자인, 배지만 "수행전" (PM 추론 기반, 확정 필요)

### 2-3. 취소 카드 (2가지)

| # | 조건 | 배지 | 좌측바 | 알림 박스 | 버튼 |
|---|---|---|---|---|---|
| 1 | CANCELLED + NEW | NEW + "취소"(X아이콘) + taskType | `#FF1744` | ✅ 빨강 | 없음 |
| 2 | CANCELLED + 확인됨 | "취소"(X아이콘) + taskType | `#FF1744` | ✅ 빨강 | 없음 |

### 2-4. ON_HOLD(보류) 카드

> **⚠️ 미확정** — 카드별 정책 작성 시 반드시 확인할 것
> - 배지 텍스트/색상
> - 좌측바 색상
> - 버튼 조합 (되돌리기?)
> - 알림 텍스트

## 5. 웹 vs 모바일 카드 CSS 차이

| 항목 | 데스크탑 | 모바일 |
|---|---|---|
| 카드 padding | 24px T/B, 16px L, 24px R | **12px** 전체 |
| 배지 font-size | 14px | **12px** |
| 이름+시간 배치 | 이름 아래행 / 시간은 헤더 우측 | **같은 줄** (space-between) |
| 시간 font-size | 14px | **12px** |
| 알림 박스 padding | 20px H, 16px V | **12px H, 8px V** |
| 버튼 사이즈 | Medium (h:36, 14px, px:16) | **Small (h:30, 13px, px:10)** |
| 아이콘 버튼 border-radius | 4px | **8px** |
| 전화 아이콘 | 없음 | 있음 (1열 모드만) |

## 6. 컨테이너 스펙

### 6-0. 카드 최대 노출 수 (웹 기준, 확정)

| 위젯 | 최대 노출 카드 수 | 초과 시 | 카드 리스트 maxHeight (2열 기준) |
|---|---|---|---|
| 변경사항 피드 | **4개** | 카드 리스트 내부 스크롤 | 824px (4×200 + 3×8) |
| 처리 필요 | **3개** | 카드 리스트 내부 스크롤 | 616px (3×200 + 2×8) |
| 클레임 | **3개** | 카드 리스트 내부 스크롤 | 616px (3×200 + 2×8) |

- 기준 카드 높이: 200px (메모·이미지 없는 기본 카드)
- 카드 간 gap: 8px
- 3열 모드: 뷰포트 기반 높이 `calc(100vh - 600px)` → 카드 리스트 flex:1
- 모바일: 높이 제한 없음

## 7. 전화 아이콘 정책

- **노출 조건**: 모바일 1열 모드 (≤ 717px)에서만
- **동작**: `tel:{keeperPhone}` 링크 → 휴대폰 전화 앱 실행
- **미노출 조건**: `keeperPhone`이 null/빈 문자열인 경우 아이콘 자체 숨김
- **mock 데이터 확장 필요**: `TicketReport`에 `keeperPhone?: string` 추가

## 8. N(미확인) 배지 정책

- **적용 범위**: 웹 + 모바일 공통
- **표시 조건**: `isNew === true`
- **소멸 조건**: 사용자가 카드 내용 확인 시 (트리거 미확정 — POLICY § 7 미결 이슈)
- **프로토타입 처리**: `isNew` 기반 표시만 구현, 소멸 트리거는 Phase 3 이후
