## 1. 기능 개요

운영자가 오늘 발생한 일감의 변경 흐름을 실시간으로 파악하고, 각 일감에 직접 개입(긴급 변경·강제완료·메모 등)할 수 있도록 제공하는 위젯이다.

| 항목 | 내용 |
|---|---|
| 위젯명 | 변경사항 피드 |
| 데이터 대상 | 오늘 생성된 일감(Ticket) 전체 |
| 주요 기능 | 상태 필터링 / 긴급 변경 / 강제완료 / 메모 입력 |
| 최대 노출 카드 수 | 웹 기준 4개 (초과 시 내부 스크롤) |
| 정렬 기준 | 최신순(기본) — 미래 확장 시 변경 가능 |

## 2. 화면 구성

### 2-1. 레이아웃

- 대시보드 콘텐츠 영역의 첫 번째 컬럼에 배치
- 흰색 배경, 8px 둥근 모서리, 1px #EEEEEE 테두리
- 헤더 영역(타이틀·버튼·필터 탭)과 카드 리스트 영역으로 구성

### 2-2. 헤더 영역

| 요소 | 내용 |
|---|---|
| 타이틀 | "변경사항 피드" — fontSize 20, fontWeight 700 |
| ⓘ 아이콘 | 위젯 기능 안내 툴팁 (클릭 시 팝업) |
| 일감 생성 버튼 | 우측 배치. 클릭 시 일감 생성 플로우 연결 |
| 필터 탭 | 5종 가로 나열 (아래 §2-3 참고) |
| 패딩 | 데스크탑 24px / 모바일 16px |

### 2-3. 필터 탭 (5종)

| 탭 키 | 라벨 | 포함 상태값 |
|---|---|---|
| ALL | 전체 | 전체 일감 |
| TASK | 업무관리 | PENDING·ASSIGNED·RESERVED·STARTED (지연/임박 제외) |
| DELAY | 지연/임박 | PENDING·ASSIGNED·RESERVED 중 dueAt 30분 이내 또는 초과 (STARTED 제외) |
| CANCELED | 취소 | CANCELED |
| COMPLETED | 완료 | RESOLVED |

- 활성 탭: 파란 배경(#E3F2FD), 텍스트 #304FFE, 카운트 배지 흰색
- 비활성 탭: 텍스트 #757575, 카운트 숫자 인라인 표시
- 카운트 상한: 99+
- 탭 줄바꿈: flexWrap wrap 허용 (좁은 화면 대응)

### 2-4. 카드 리스트

- 카드 간 gap: 8px
- 패딩: 상하 16px / 좌우 24px (모바일 16px)
- 카드 수 ≤ 4: 자연 높이
- 카드 수 > 4: 첫 4개 카드 실측 높이 합산으로 maxHeight 고정 + 내부 스크롤
- 모바일 1열 탭 구간: 높이 제한 없음

### 2-5. 카드 구성 요소 (상태별 분기)

**공통 상단 행**
- 좌측 색상바: 상태·지연·긴급 여부에 따라 색상 결정
- 상태 배지(NEW · 상태값 · 업무형태)
- 우측: 완료 기한(dueAt) 또는 시작 시각

**상태별 카드 구성**

| 상태 | 메모 inputbox | 액션 버튼 |
|---|---|---|
| PENDING (미배정) | 업무관리 탭에서 표시 | 배정 하기 / 일감 취소 |
| ASSIGNED (배정됨) | 업무관리 탭에서 표시 | 긴급 변경 / 배정 해제 / 시작하기 |
| RESERVED (수행전) | 업무관리 탭에서 표시 | 긴급 변경 / 시작하기 |
| STARTED (수행중) | 업무관리 탭에서 표시 | 긴급 변경(업무관리 탭 한정) / 시작 취소 / 완료 하기 |
| RESOLVED (완료) | 읽기 전용 박스 (메모 있을 때) | 후속 일감 생성 |
| CANCELED (취소) | 없음 | 없음 |
| HOLD (보류) | 없음 | 없음 |

**긴급 변경 적용 상태**: PENDING·ASSIGNED·RESERVED (STARTED는 업무관리 탭에서만)

## 3. 사용자 시나리오

### 시나리오 A — 정상 조회
```
1. 운영자가 대시보드에 접속한다.
2. 변경사항 피드 위젯에 오늘 생성된 일감 카드들이 로드된다.
3. 기본 탭은 "전체"로 설정된 상태로 모든 일감이 표시된다.
4. 운영자는 각 카드의 상태 배지·완료 기한을 확인해 우선순위를 판단한다.
```

### 시나리오 B — 필터 탭 사용
```
1. 운영자가 "지연/임박" 탭을 클릭한다.
2. dueAt 기준 30분 이내이거나 이미 초과된 일감만 필터링되어 표시된다.
3. 운영자는 해당 일감에 대해 긴급 변경 또는 강제완료 처리를 진행한다.
```

### 시나리오 C — 긴급 변경 처리
```
1. 운영자가 지연/임박 탭의 ASSIGNED 카드에서 "긴급 변경" 버튼을 클릭한다.
2. 확인 팝업이 나타난다.
3. 확인 선택 시 해당 일감이 긴급 건으로 변경되고, 버튼이 "긴급 취소"로 교체된다.
4. 키퍼 앱에 긴급 건으로 표시된다 (BE 처리).
```

### 시나리오 D — 메모 입력 및 저장
```
1. 운영자가 업무관리 탭의 카드를 확인한다.
2. 카드 하단 inputbox에 메모를 입력하고 "저장" 버튼을 클릭한다.
3. 텍스트 또는 이미지 중 하나라도 있으면 저장 버튼이 활성화된다.
4. 저장 완료 시 카드가 비활성화 처리된 상태로 전환된다.
```

### 시나리오 E — 지점 필터 적용 시
```
1. 운영자가 상단 탭에서 특정 지점을 선택한다.
2. 변경사항 피드의 카드가 해당 지점 일감만으로 즉시 갱신된다.
3. 모든 필터 탭 카운트도 해당 지점 기준으로 재계산된다.
```

### 시나리오 F — 위젯 OFF
```
1. 운영자가 위젯 설정에서 변경사항 피드를 OFF한다.
2. 위젯 전체가 화면에서 사라지고 나머지 위젯이 재배치된다.
3. 모바일 탭 구간에서는 세그먼트 탭에서 '변경사항 피드' 탭도 함께 제거된다.
```

## 4. 예외 케이스 (Edge Case)

| 상황 | 사용자 경험 |
|---|---|
| 오늘 생성된 일감이 없음 | "조회된 일감이 없습니다." 문구 중앙 표시 |
| 선택한 필터 탭에 해당 일감 없음 | "조회된 일감이 없습니다." 문구 중앙 표시 |
| 데이터 로딩 중 | "로딩 중..." 표시 |
| 카드 수 > 4 | 첫 4개 기준 maxHeight 고정 + overflowY auto |
| 메모 텍스트·이미지 모두 없음 | 저장 버튼 비활성화 |
| 이미지 5장 초과 업로드 시 | 토스트: "사진은 최대 5장까지 등록할 수 있습니다." |
| 배정 해제 API 실패 | 팝업 닫힘 + 토스트: "배정이 해제되지 않았습니다. 다시 시도해 주세요." |
| RESOLVED 카드 — 메모 없음 (Type A) | 읽기 전용 박스 미노출. 후속 일감 생성 버튼만 표시 |
| RESOLVED 카드 — 메모 있음 (Type B) | 읽기 전용 박스 + 후속 일감 생성 버튼 표시 |

## 6. 디자인 요구사항

### 위젯 외곽
- 배경 흰색, border-radius 8px, outline 1px #EEEEEE
- overflow hidden

### 헤더
- 데스크탑 padding: 24px 24px 18px / 모바일: 16px 16px 12px
- 타이틀과 필터 탭 사이 gap 16px

### 필터 탭
- 활성: bg #E3F2FD, 텍스트 #304FFE, 카운트 배지 흰색 배경 #2962FF 텍스트
- 비활성: 텍스트 rgba(0,0,0,0.38)
- flexWrap: wrap (좁은 화면 2줄 허용)
- 카운트 상한: `count > 99 ? '99+' : count`

### 카드 좌측 색상바 기준
| 조건 | 색상 |
|---|---|
| 지연/임박 (dueAt 초과·30분 이내) | #FF1744 (빨간) |
| 긴급 건 (isUrgent) | #FF1744 (빨간) |
| 완료 + 지연 이력 있음 | #FF1744 (빨간) |
| 일반 완료 | #9E9E9E (회색) |
| 취소 | #9E9E9E (회색) |
| 보류 | #FF1744 (빨간) |
| 그 외 | #9E9E9E (회색) |

### 상태 배지 (flexWrap wrap 적용)
- 컨테이너: flexWrap wrap / overflow visible
- 배지 개별: whiteSpace nowrap / flexShrink 0
- 노출 순서: NEW → 상태 배지 → 업무형태 배지

### 메모 inputbox (업무관리 탭, 수행 전·중)
- 배경: #F5F5F5, padding 12px, border-radius 8px
- textarea: 104px (4 rows), MUI Outlined
- 이미지 영역 배경: white / padding 8px
- 저장 버튼 활성: 텍스트 OR 이미지 중 하나 이상 존재 시

### 읽기 전용 메모 박스 (RESOLVED + 메모 있음)
- 배경 #F5F5F5 / 테두리 없음 / padding 12px 균일 / 자연 높이

### 높이 정책
- 카드 수 > 4: ResizeObserver로 첫 4개 실측 → maxHeight = 합산 높이 + gap(8×3) + 패딩(32)
- 측정 전 opacity 0 → 측정 완료 후 1 (깜빡임 방지)

### 반응형
- 웹 3열: 위젯 1개 컬럼 (416px 이상 보장)
- 모바일: padding 16px, 높이 제한 없음

### 접근성
- ⓘ 버튼: aria-label "안내 보기"
- 일감 생성 버튼: 명시적 텍스트 포함
