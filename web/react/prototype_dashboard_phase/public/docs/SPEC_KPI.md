## 1. 기능 개요

운영자가 대시보드에 접속했을 때, 현재 시점의 업무 상태를 한눈에 파악할 수 있도록
4개의 요약 지표 카드를 제공한다.

| 카드명 | 한 줄 정의 |
|---|---|
| 업무 현황 | 지금 처리해야 할 일감이 몇 건인지 |
| 미해결 이슈 | 아직 완료되지 않은 이슈·보류 건이 몇 건인지 |
| 미확인 클레임 | 파트너사(운영자)가 아직 처리하지 않은 클레임이 몇 건인지 |
| 오늘 업무 달성률 | 전체 잔여 업무 중 오늘 완료된 비율이 얼마인지 |

## 2. 화면 구성

### 2-1. 레이아웃
- 대시보드 최상단에 가로 배치
- 웹(넓은 화면): 4개 카드 1줄 배치
- 웹(중간 화면) / 모바일: 2×2 그리드 배치
- 각 카드: 아이콘 + 카드명 + 숫자 + 단위

### 2-2. 카드별 표시 정보

**업무 현황**
- 표시: `N건`
- 의미: 시작 가능 일시 기준 오늘 이하이며 미완료인 일감 수 (미배정·배정됨·수행전·수행중)
- 완료되거나 취소된 일감은 카운트에서 제외
- 과거 미완료 건 전체 포함

**미해결 이슈**
- 표시: `N건`
- 의미: 현재 시점 기준 미완료인 이슈·보류 건 수
- "미해결 이슈" 카드는 이슈 위젯의 두 탭(이슈 탭·보류 탭)의 합산이다
  - 이슈 탭: 접수됨(REPORTED) 상태 — 운영자가 처리 대기 중인 이슈
  - 보류 탭: 보류(HOLD) 상태 — 즉시 처리가 어려워 일시 중단된 이슈
  - 두 탭을 합산하여 "미해결 이슈" 카드 수치로 표시
- 완료되거나 취소된 이슈는 카운트에서 제외

**미확인 클레임**
- 표시: `N건`
- 의미: 파트너사(운영자)가 아직 처리하지 않은 클레임 건 수
- 처리 대기(PENDING) 상태만 포함
- 클레임 처리 흐름 (2안): 고객사 등록(처리 대기) → 파트너사 인정 또는 이의제기 → 종결
- 이의제기(DISPUTED)·인정완료(ACCEPTED)·이의제기 후속 처리 완료(DISPUTE_COMPLETED)는 파트너사 처리가 완료된 종결 상태이므로 미확인 클레임에서 제외

**오늘 업무 달성률**
- 표시: `N%` (보조: `완료건/전체건`)
- 의미: 오늘 해결해야 할 전체 업무 중 오늘 완료된 비율
- 전체(분모) = 오늘 00:00:00 기준 미완료 전체 스냅샷 + 당일 신규 생성 건 누적
- 완료(분자) = 오늘 완료된 일감 + 이슈 + 클레임
  - 클레임 완료: 인정완료(ACCEPTED) + 이의제기(DISPUTED) + 이의제기 후속 처리 완료(DISPUTE_COMPLETED)
- D+1 00:00:00 리셋

## 3. 사용자 시나리오

### 시나리오 A — 정상 조회
```
1. 운영자가 대시보드에 로그인한다.
2. 화면 상단에 4개의 KPI 카드가 로딩된다.
3. 운영자는 각 카드의 숫자를 통해 현재 업무 상태를 파악한다.
4. 오늘 업무 달성률 카드에서 "완료건/전체건"을 확인해 진행률을 판단한다.
```

### 시나리오 B — 지점 필터 적용 시
```
1. 운영자가 상단 탭에서 특정 지점을 선택한다.
2. KPI 카드 4개의 숫자가 해당 지점 기준으로 즉시 갱신된다.
3. 운영자는 특정 지점만의 업무 현황을 파악한다.
```

### 시나리오 C — 특정 KPI 카드 OFF 시
```
1. 운영자가 위젯 설정에서 특정 KPI 카드를 OFF한다.
2. 해당 카드가 화면에서 즉시 사라진다.
3. 나머지 카드들이 빈 공간 없이 재배치된다.
4. 실시간 관리 지표 전체를 OFF하면 4개 카드 모두 사라진다.
```

### 시나리오 D — 안내 정보 확인
```
1. 운영자가 "실시간 관리 지표" 옆의 ⓘ 아이콘을 클릭한다.
2. 툴팁이 나타나며 지표의 의미를 간략히 안내한다.
3. 툴팁 외부 영역 클릭 시 툴팁이 닫힌다.
```

### 시나리오 E — 수치 자동 갱신
```
1. 운영자가 대시보드를 열어둔 상태에서 다른 운영자가 이슈를 완료처리한다.
2. KPI 카드 수치가 1분 이내(실운영) 또는 30초 이내(mock)로 자동 갱신된다.
3. 운영자는 별도 새로고침 없이 최신 현황을 확인한다.
```

## 4. 예외 케이스 (Edge Case)

| 상황 | 사용자 경험 |
|---|---|
| 진행 중인 일감이 없음 | 업무 현황: `0건` 표시 |
| 이슈·클레임이 전혀 없음 | 미해결 이슈 `0건`, 미확인 클레임 `0건` |
| 오늘 완료된 업무가 없음 | 달성률: `0%`, 보조 `0/N건` |
| 데이터 로딩 중 | 모든 카드 숫자 `0`으로 표시 (로딩 완료 후 갱신) |
| 모든 업무가 완료됨 | 달성률: `100%` |
| KPI 카드 전체 OFF | 카드 영역 자체가 사라짐. 위젯 설정에서 다시 ON 가능. |

## 6. 디자인 요구사항

### 카드 레이아웃
- 각 카드는 흰색 배경, 모서리 둥글게 처리
- 아이콘은 카드 좌측 상단
- 숫자는 카드 우측 하단, 굵은 폰트로 강조
- 달성률 카드의 숫자는 파란색 계열로 표시

### 반응형
- 넓은 화면: 4개 가로 1줄
- 중간 화면 / 모바일: 2×2 그리드

### 접근성
- 각 아이콘에 대체 텍스트 제공
- 숫자 로딩 중 깜빡임 없이 0 → 실제값으로 자연스럽게 전환
